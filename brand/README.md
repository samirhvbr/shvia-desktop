# ShvIA Desktop brand

The active desktop identity is **Shield**, selected from the sibling Web checkout's
`brand-explorations/brand-v2` reference package on 2026-09-27. Its flat production
mark has a graphite/titanium shield, a cobalt left hemisphere and six connection nodes.

- `shield-app.svg` and `shield-symbol.svg` are the editable desktop sources.
- `shvia-desktop-icon-1024.png`, `shvia-mark.png` and `src-tauri/icons/` are their native exports.
- `versao2-portal/` preserves the previous Portal artwork and the icons it replaced.

Use cobalt `#2350E6`, graphite `#2A2D32`, titanium `#BFC4CA`, deep blue `#0E2468`,
light blue `#6E97FF`, mist `#F4F5F7` and ink `#111317`. The signed package and store
release are separate build operations; changing these assets does not publish a build.
